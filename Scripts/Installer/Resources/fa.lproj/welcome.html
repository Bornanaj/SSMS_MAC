SSMS for Mac

یک کلاینت بومی macOS برای Microsoft SQL Server، با همان ساختار SQL Server Management Studio: Object Explorer، ادیتور T-SQL با IntelliSense، گرید نتایج، نقشهٔ اجرا، اسکریپت‌ساز، مدیریت امنیت و Agent، و گزارش‌های استاندارد.

مستقیم با SQL Server حرف می‌زند؛ هیچ چیز دیگری لازم نیست نصب شود — نه درایور ODBC، نه FreeTDS، نه JVM. پروتکل TDS داخل خود برنامه پیاده‌سازی شده است.

این نصب‌کننده SSMS for Mac را در پوشهٔ Applications قرار می‌دهد. چون نوشتن در آن پوشه دسترسی مدیر می‌خواهد، رمز عبورتان پرسیده می‌شود.
