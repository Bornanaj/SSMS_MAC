پیش از نصب

پیش‌نیازها

  • macOS 14 (Sonoma) یا جدیدتر، روی Apple silicon یا Intel
  • یک SQL Server 2016 تا 2022، یا Azure SQL Database، یا Azure SQL Managed Instance در دسترس

اتصال

  • از منوی File › Connect to Server یا دکمهٔ + بالای Object Explorer.
  • فیلد سرور این قالب‌ها را می‌پذیرد: host، host,port، host\INSTANCE و tcp:host,port.
  • برای سرور محلی یا توسعه با گواهی self-signed، گزینهٔ Trust server certificate را روشن بگذارید.

دربارهٔ این نسخه

این نسخه با امضای ad-hoc ساخته شده، نه با Apple Developer ID. نصب از همین نصب‌کننده بهترین راه است: اپی که در Applications نوشته می‌شود پرچم quarantine نمی‌گیرد و بعد از نصب بدون هیچ هشداری باز می‌شود.
