Installation complete

SSMS for Mac is now in your Applications folder. Open it from Launchpad or Spotlight.

On first launch, choose File › Connect to Server and enter your server name and login. Saved passwords are kept in your login keychain, never in a file.

Keyboard shortcuts worth knowing: ⌘R execute, ⌘. cancel, ⌘L go to line, ⌃Space IntelliSense, ⌥⌘E expand wildcards.
