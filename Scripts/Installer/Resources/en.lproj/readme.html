Before you install

Requirements

  • macOS 14 (Sonoma) or later, Apple silicon or Intel
  • A reachable SQL Server 2016–2022, Azure SQL Database, or Azure SQL Managed Instance

Getting connected

  • Choose File › Connect to Server, or the + button above the Object Explorer.
  • The server field accepts host, host,port, host\INSTANCE and tcp:host,port.
  • Leave Trust server certificate on for a local or development server with a self-signed certificate.

About this build

This build is signed ad hoc rather than with an Apple Developer ID. Installing through this installer is the smoothest route: the app it writes to your Applications folder is not quarantined, so it opens normally afterwards.
