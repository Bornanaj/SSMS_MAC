SSMS for Mac

A native macOS client for Microsoft SQL Server, in the shape of SQL Server Management Studio: Object Explorer, a T-SQL editor with IntelliSense, a results grid, execution plans, scripting, security and agent management, and standard reports.

It talks to SQL Server directly. There is nothing else to install — no ODBC driver, no FreeTDS, no JVM. The TDS protocol is implemented inside the app.

This installer will place SSMS for Mac in your Applications folder. You will be asked for your password, because writing there needs administrator rights.
